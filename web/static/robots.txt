# =============================================================================
# robots.txt = 検索エンジンへの案内
#
# ▼ ★これは「お願い」です。「見せない設定」ではありません。
#
#   行儀のよい検索エンジンは従いますが、従わない相手もいます。
#   ★入られては困るものは、必ずログインで守ってください。
#   ここに Disallow と書くだけでは、誰でもURLを直接開けます。
#
#   むしろ「隠したい場所の一覧」をここに書くと、
#   そこを見に行く相手への案内板になってしまいます。
#
# ▼ ★置き場所はサイト直下でなければならない
#
#   検索エンジンは http://ドメイン/robots.txt しか見に来ません。
#   このファイルは web/static/ にありますが、
#   internal/router/router.go でサイト直下に出しています。
#
# ▼ 開発中は気にしなくてよい
#
#   localhost には検索エンジンは来ません。
# =============================================================================

User-agent: *

# ログイン画面と、JavaScript向けのURLは検索結果に載せる意味がない。
Disallow: /auth/
Disallow: /api/

# それ以外は載せてよい。
Allow: /
